## 3. 배경 및 문제 정의

- 연휴·징검다리 연휴 소식이 나오면 "연차 며칠 쓰면 며칠 쉬지?"를 매번 달력 보며 직접 계산함
- 대체공휴일·임시공휴일이 수시로 추가되어 기존 달력 이미지·블로그 글이 금방 틀려짐
- 내 연차가 몇 개인지(입사 1년 미만, 3년차 가산 등) 정확히 모르는 직장인이 많음

## 4. 핵심 기능 (MVP)

### 4-1. 홈 — 다음 연휴

- 다음 연휴까지 D-day
- 연휴 기간(시작~끝)과 총 쉬는 날 수
- 올해 남은 공휴일 목록 (대체공휴일 표시)

### 4-2. 연차 추천 (메인)

- 연차 1개 / 2개 / 3개 탭
- 각 탭에서 가장 길게 쉴 수 있는 구간을 추천
  - 예: "연차 2개 → 10월 2일(금)~10월 11일(일), 10일 연속"
- 정렬: 연속 휴일 수 → 효율(쉬는 날 ÷ 쓴 연차)
- 범위: 오늘 이후 ~ 내년 12월 31일 (내년 데이터가 아직 없으면 올해만)
- 각 추천 카드에 "연차 쓸 날짜" 표시

### 4-3. 내 연차 계산

- 입사일 입력 → 오늘 기준 발생 연차 계산 (근로기준법 제60조)
  - 입사 1년 미만: 1개월 개근 시 1일, 최대 11일
  - 1년 이상(80% 이상 출근): 15일
  - 3년 이상: 최초 1년 초과 근속 2년마다 1일 가산, 최대 25일
- 다음 연차 증가일 안내 ("2027년 3월 2일부터 16일")
- 안내 문구: "입사일 기준 참고용이에요. 회계연도 기준인 회사는 실제와 다를 수 있어요."

### 4-4. 설정 (없음)

- 주 5일(토·일 휴무) 고정 — 따로 설정 화면을 두지 않음
- 노동절(5/1)은 공휴일 API에 공휴일로 들어 있어 별도 처리 없이 그대로 반영 (토요일이면 "대체공휴일(노동절)"도 API에 있음)
- 개인정보처리방침 링크와 계산 기준 안내는 각 탭 화면 하단

## 5. 화면 구성

하단 탭 3개: **홈 / 연차 추천 / 내 연차** (설정 화면 없음). 토스 디자인 언어 유지 (블루 단일 액센트, 화이트 카드 + 얇은 보더). 연속 휴일 수를 큰 숫자로 강조.

## 6. 데이터/기술

- **데이터 소스:** 공공데이터포털 "한국천문연구원_특일 정보" — 공휴일 정보 조회(`getRestDeInfo`)
- **호출 구조:** 기존 Cloudflare Worker `public-data-proxy`에 `/holidays?year=YYYY` 경로 추가
  - KV 캐시 키 `holidays:{year}`, 하루 단위 갱신 (임시공휴일 반영)
  - 실패 시 마지막 정상 데이터 fallback (빨래 앱과 동일)
  - 데이터 양이 연도당 20건 안팎이라 1회 호출로 충분 → KV 한도 영향 거의 없음
- **연차 추천·연차 계산:** 전부 앱 내부 계산 (API 불필요)
- **개발 방식:** 앱인토스 SDK, Claude Code
- **인프라 비용:** 0원

## 9. 리스크 및 대응

| 리스크 | 대응 |
|---|---|
| 내년 공휴일 데이터 미등록 | 연말 전에는 내년 데이터가 비어 있을 수 있음 → "내년 공휴일은 아직 발표 전이에요" 안내, 주말만으로 계산하지 않음 |
| 임시공휴일 급작스런 지정 | KV 하루 단위 갱신으로 최대 하루 지연 |
| 연차 계산 오해 | 회사 규정과 다를 수 있음 → 참고용 문구 필수, 법 조항 링크 |
| API 응답 형식 | 결과가 1건이면 배열이 아닌 객체, 0건이면 빈 문자열로 옴 → 파싱 시 정규화 필수 |
